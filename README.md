# Occasionofferte demo

Gepubliceerde demo van een interactieve occasionofferte met F&I (neutrale huisstijl "Demo Dealer").
Gegenereerd met `npm run build:site` uit de broncode-repository; hier niet met de hand aanpassen.

- Verkopers loggen in op de startpagina.
- Klanten openen alleen hun eigen offerte via een persoonlijke link (`?o=…`).
- Gegevens worden opgeslagen in Supabase (EU); toegang wordt in de database afgedwongen.
